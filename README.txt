DroBinG Backup 1.2 - Windows x64

Переносимая программа резервного копирования файлов VDS по SSH на выбранный диск.
Распакуйте архив в отдельную папку и запустите DroBinGBackup.exe.
Укажите собственный сервер, SSH-порт, логин и пароль. Получите и сверьте ключ SSH, выберите носитель и пути на сервере, затем сохраните настройки.
Поля подключения в новой установке пустые. В пакет не включены настройки, учётные данные или копии сервера разработчика. Порт 22 - стандартное начальное значение, его можно изменить.

Подробная справка: кнопка «? Справка» / F1 или файл HELP.txt.
Python на ПК не требуется; на VDS нужен python3. Готовая программа рассчитана на Windows x64. Сборка из Source.zip требует C++ Build Tools и Windows SDK, инструкция в build.ps1.

Расписание не зависит от открытого окна: задачу создаёт кнопка сохранения с включённым автозапуском. Нужны включённый ПК, вход в Windows, подключённый диск и интернет. На новом ПК пароль и расписание настраиваются заново.
Пароль хранится в Windows Credential Manager текущего пользователя. Архивы на носителе не зашифрованы; защищайте их от посторонних.
Копируются выбранные пути, а не вся ОС. SQLite копируются через online backup; для других СУБД используйте их штатные дампы. Общей атомарности всех файлов работающего сайта нет.
